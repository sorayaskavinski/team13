# Task Forge — Team 13

A modern, responsive task management application designed to help users streamline their workflow, organize daily tasks, and boost productivity efficiently.

---

## 🚀 Features

- **Task Management:** Create, view, update, and delete tasks (CRUD functionality).
- **Status Tracking:** Mark tasks as pending, in progress, or completed.
- **Interactive Dashboard:** Clean and intuitive user interface for seamless task navigation.
- **Real-Time Updates:** Dynamic state management providing immediate UI feedback upon user actions.
- **Responsive Design:** Optimized layout for desktop and mobile screen sizes.

---

## 🛠️ Tech Stack & Languages

- **Programming Languages:** 
  - **C#** (Backend / Application Logic)
  - **HTML5 & CSS3** (Structure & Styling)
  - **JavaScript** (Client-side Interactivity)
- **Frameworks & Libraries:** 
  - **.NET / ASP.NET Core**
  - **Blazor** (Interactive Web UI)
- **Version Control:** Git & GitHub

---

## 📋 Prerequisites

Before running this project, ensure you have the following installed on your machine:

- [.NET SDK 8.0](https://dotnet.microsoft.com/download) (or latest LTS version)
- An IDE such as [Visual Studio 2022](https://visualstudio.microsoft.com/) or [Visual Studio Code](https://code.visualstudio.com/) with C# Dev Kit extension.
